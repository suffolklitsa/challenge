# Starter kits

One folder per lane with a template to start from: a README already laid out the way `tools/check_submission.py` expects, an `AI-USE.md` to fill in, and lane-specific starting material. Kits are being built (see the issues); lane C will start from the LIT Lab's Docassemble tools.

Every submission needs:

- `README.md` with your team name as the title and sections **Lane**, **What it does**, **How to use it** and **Where this fails**
- `AI-USE.md` with a **Tools** section (write "None" if you used none)

Check yours: `python3 tools/check_submission.py path/to/your-entry`.
