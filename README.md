# challenge

LITSA's annual challenge at Suffolk Law: a moot court competition and a build competition on the same case file, set in the fictional Commonwealth of Tremont.

Each year has its own folder. This repo holds everything public: rules, FAQ, schedule, lane briefs, judging rubrics, starter kits, scoring and bracket tools, a submission checker, and case materials once they are released on their scheduled dates.

## Contributing

Start with an issue labeled `good first issue` or `no code needed`. Click **Code → Codespaces → Create codespace** to get a ready-to-use editor in your browser; nothing to install. See the org's [contributing guide](https://github.com/suffolklitsa/.github/blob/main/CONTRIBUTING.md).
