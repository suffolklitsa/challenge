# Build lanes (draft)

Every lane works inside the same case. Lanes A and C are designed so a first-year with no coding can compete.

| Lane | You are | You build |
|---|---|---|
| **A. Legal aid intake** | An intake coordinator at a legal aid office | A way to triage affected patients: cancelled care, wrong bills, exposed records, sensitive disclosures |
| **B. Small firm** | A junior associate | A case assessment for a client caught in the fallout |
| **C. Courts and self-help** | A court-help designer | Forms or a guided interview for patients disputing charges without a lawyer |
| **D. AI governance** | In-house counsel at the health system | The review that should have happened before rollout: vendor terms, logging, human sign-off, testing |
| **E. Breach response** | Outside counsel, first 72 hours | A notification plan, draft notices, and the insurer notice |
| **F. Dispute resolution** (optional) | An online dispute resolution designer | A process to resolve thousands of small billing claims fairly |

Tools in every lane are run against unseen test cases on the day.
