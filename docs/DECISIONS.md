# Decisions

**2026-10-19. Public from day one.** Rules, lanes, rubrics, starter kits and tools are public as soon as they're drafted. Case materials release on fixed dates from the private writers' repo.

**2026-10-19. One repo across years,** with a folder per year, so tools and lessons carry forward.

**2026-09-27. One case feeds both competitions,** in a fictional state with a closed universe, so research is even across schools and the answer key can't shift.

**2026-09-27. AI use is allowed and disclosed.** Teams can't be monitored on their own accounts, so the rule is disclosure, with transcripts and a note on how output was checked.

**2026-09-27. Not all code.** Structured work product counts. Every submission says where it fails.
